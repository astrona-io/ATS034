# Pod Security Profiles

This module develops pod Security Profiles. Use the explanations to connect intended behavior with responsible components and observable evidence.

## Learning Goals

- Compare Privileged, Baseline and Restricted profiles.
- Explain the purpose and limits of security-context fields.
- Relate image users and writable paths to profile compatibility.
- Distinguish compliant configuration from complete application security.

## Before You Start

Examples illustrate declared relationships and reasoning. No execution environment is required or claimed.
